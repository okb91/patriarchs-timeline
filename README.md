# От Адама до Иисуса Христа: патриархи и древности

Интерактивный таймлайн: допотопные патриархи, ветвь Каина, сыновья и внуки Ноя, полное родословие Христа, история Израиля и археология Ближнего Востока и Крыма по библейской хронологии (масоретский текст / Септуагинта) с наложением археологических эпох, памятников и климатических событий в общепринятых датах.
