# Патриархи и древности

Интерактивный таймлайн: допотопные патриархи, сыновья Ноя и линия Сима до Авраама по библейской хронологии (масоретский текст / Септуагинта) с наложением археологических эпох, памятников и климатических событий в общепринятых датах.

Страница статическая: `index.html`, без сборки. Публикуется через GitHub Pages.
